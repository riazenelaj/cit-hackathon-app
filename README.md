# Kerpudhat Hackathon Project (24h Challenge)

## About the Project  
Kerpudhat is a prototype platform developed during a 24-hour hackathon on CIT university.  
The theme was "Master the Future," focused on strengthening community engagement among students, faculty, alumni, and local businesses.

The project aims to provide a space for the CIT community to connect, communicate, and collaborate effectively.

## What We Built  
This prototype includes the following core features:

- *Interactive Platform*  
  An online space designed to connect CIT students, staff, and local businesses.

- *Company Challenges & Volunteering*  
  A system where companies can post challenges or projects, and students can volunteer to solve them.

- *Community Engagement*  
  Features that promote participation and collaboration among all stakeholders.

Note: This is a working prototype developed under 24-hour time constraints. It is not a fully complete product but a proof of concept.

## Tech Stack  
- *Backend*: Started in Python, later migrated to NestJS  
- *Frontend*: Angular with TypeScript

## Deliverables  
- Presentation (shared via Google Drive)  
- Functional prototype showcasing the concept
